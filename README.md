
#  Loksuvidha's Charcha

Loksuvidha's Charcha is a real-time chatroom application where users can randomly join or create chat groups to engage in spontaneous discussions on any topic. It provides a smooth user experience with real-time messaging, room-based discussions, and clean navigation — ideal for anonymous or topic-based group chats.
